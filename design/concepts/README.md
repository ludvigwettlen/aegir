# Aegir color and blur concepts

Generated with the built-in image generation tool as exploratory UI mockups. These are visual directions, not pixel-accurate specifications for the app.

## 01 — Frosted workspace

Prompt: A high-fidelity Aegir desktop Tasks screen with a narrow navigation rail, central Upcoming task list, and right context chat pane. Use white and warm-white surfaces, a softly blurred buttery-yellow glow behind the content, translucent glass panels, and restrained lime-green active states. Keep dividers fine, typography precise, and whitespace generous. Use a straight-on 1440×900 screen capture. Keep all text and controls crisp; apply blur only to ambient backgrounds and translucent panels. No device frame, hands, watermark, or perspective.

## 02 — Yellow editorial

Prompt: A high-fidelity Aegir desktop Tasks screen preserving the top navigation, left task rail, central Upcoming list, and right General chat pane. Use a strong sunflower-yellow header, pure-white content canvas, lime-green primary action, and deep near-black headings. Add blurred yellow and lime light blooms at the canvas edges and translucent white secondary controls. Use an oversized editorial heading, compact utility labels, and thin dividers. Keep the layout straight-on at 1440×900; text and controls remain sharply readable. No device frame, watermark, or perspective.

## 03 — Lime glass

Prompt: A high-fidelity Aegir desktop Tasks screen preserving the top navigation, left task rail, central Upcoming list, and right General chat pane. Use translucent milky-white panels over a pale warm canvas, with large defocused lime and lemon light pools behind the columns. Apply soft backdrop blur to panels, subtle translucent outlines, lime interactive accents, yellow warmth and notifications, and dark green-black text. Keep a usable dense desktop layout at 1440×900. All typography and controls must remain sharp; blur only the background and the area behind translucent panels. No dark mode, device frame, watermark, or perspective.
